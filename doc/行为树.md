# 行为树

###### 行为树通用数据说明

```sh
1.除了root节点，所有节点都有返回结果
2.返回结果有3种，success,fail,unknown,一般情况 unknown 不需要处理，只需要关注success和fail即可
3.ifelse 节点按情况决定是否需要处理check节点返回unknown 的情况
```

###### 默认通用行为节点

根节点  (root)

```json
//前后端交互结构
{
	"node_type":"root",  //节点类型
	"node":null          //子节点json结构，可以是其他通用行为节点或行为节点 实际情况不能为 null
}
```

永真节点 (always_true_node)

```json
//前后端交互结构
{
	"node_type":"always_true_node",  //节点类型
	"node":null          //子节点json结构，可以是其他通用行为节点或行为节点 实际情况不能为 null
}
// 无论node 节点的执行结果时success还是fail,本节点的结果都返回success
```

ifelse节点 (ifelse_node)

```json
//前后端交互结构
{
	"node_type":"ifelse_node",  //节点类型
	"check":null,				//需要判断的节点json,可以是其他通用行为节点或行为节点  实际情况不能为 null
	"success":null,				//判断节点为true执行的节点,可以是其他通用行为节点或行为节点 实际情况不能为 null
	"fail":null,				//判断节点为false执行的节点,可以是其他通用行为节点或行为节点 实际情况不能为 null
	"unknown":null          	//判断节点不为true和false时执行的节点,可以是其他通用行为节点或行为节点
}

//对check节点的返回结果进行判断，如果返回success,则执行success节点，如果返回fail，则执行fail节点，（可选）如果
//返回unknown，则执行unknown节点， 将执行节点的结果作为本节点的结果返回
```

循环节点（判断结果） (loop_bool_node)

```json
//前后端交互结构
{
	"node_type":"loop_bool_node",  //节点类型
	"bool":null,				//true 或 false ,子节点返回结果与该参数一致这停止，否则一致循环 实际情况不能为 null
	"node":null				//子节点,可以是其他通用行为节点或行为节点 实际情况不能为 null
}
// 执行节点node,直到节点返回的结果与bool设定的值相同，本节结果只有success,否则就是一直在循环
```

循环节点（次数） (loop_num_node)

```json
//前后端交互结构
{
	"node_type":"loop_bool_node",  //节点类型
	"num":1,					// 次数，子节点循环这么多次 实际情况不能为 null
	"node":null				//子节点,可以是其他通用行为节点或行为节点 实际情况不能为 null
}
//执行节点node,执行 num设定的次数，并且把最后一次node执行的结果作为本节点的结果返回
```

选择节点 (selector_node)

```json
//前后端交互结构
{
	"node_type":"selector_node",  //节点类型
	"nodes":[]					//子节点列表,可以是其他通用行为节点 实际情况不能为 [] 和 null
}
//从左到右执行nodes里面的节点，执行到第一个返回success的节点后停止，然后本节点返回success,
//如果执行到最后一个也没有success，则本节点返回fail
```

顺序节点(sequence_node)

```json
//前后端交互结构
{
	"node_type":"sequence_node",  //节点类型
	"nodes":[]					//子节点列表,可以是其他通用行为节点 实际情况不能为 [] 和 null
}
//从左到右执行nodes里面的节点，执行到第一个返回fail的节点后停止,然后本节点返回fail,
//如果执行到最后一个也没有fail，则本节点返回success
```

取反节点(negation_node)

```json
//前后端交互结构
{
	"node_type":"negation_node",  //节点类型
	"node":null					//子节点,可以是其他通用行为节点 实际情况不能为null
}
//对子节点node的结果取反，并且作为本节点的结果返回
```

平行节点(parallel_node)

```json
//前后端交互结构
{
	"node_type":"parallel_node",  	//节点类型
	"nodes":[]					//子节点列表,可以是其他通用行为节点 实际情况不能为 [] 和 null
}
//执行nodes中的所有节点，并且把最后一个节点执行的结果作为本节点的结果返回
```

叶子节点(leaf)  也可以称为 行为节点

```json
//前后端交互结构
{
	"node_type":"leaf",  	//节点类型
	"behavior_id":322,  	//行为节点id
	"args":[]					//行为节点参数列表
}
```

‍

###### 叶子节点参数类型

```json
int :  参数值必须为整数
string : 参数值必需为字符串    
atom :  前端判断同 string ,后端数据不一致  
```
