# 任务配置说明

### 1.运行状态

**任务配置说明**

```json
{
	// 结果关系库表名  	
	"table_name":"t_daily_run_status",	
	//执行任务读取的文件，csv文件 	
	"task_file":"运行状态.csv",			
	//统计区间说明 
	//整数：时间区间 (统计数据时间范围是 {执行时间 - 86400s,执行时间}) 配置方式 "interval_time":86400	
	//["hour",2]: 小时区间 （统计数据时间范围是 {执行时间的小时数整点时间(向前) - 2 * 3600s,执行时间的小时数整点时间(向前)}）配置方式 "interval_time":["hour",2]
    //["day",4] : 每日区间 （统计数据时间范围是 {执行时间向前的第一个4点 ，执行时间向前的第二个 4 点 }）配置方式 "interval_time":["day",4]
 	"interval_time":86400					
}
```

**数据文件说明**

|表头|​`da_unit`|​`A`|​`B`|​`C`|​`D`|​`E`|​`rule`|​`table_key`|​`data_valid_time`|
| ------| ----------| ---------| ---------| ---------| ---------| ---------| --------------| ---------| ------------------|
|表头|采集单元|采集点A|采集点B|采集点C|采集点D|采集点E|数据判断规则|入库key|数据最大有效时间|
|示例|​`TEST`|​`TAG1`|||||​`A > 10`|​`TEST_TAG1`|​`300`|

**算法说明**

```json
///根据 任务配置 说明中的 interval_time 参数 计算数据起止时间
///查询 da_unit 以及 A参数 对应的采集点起止时间内数据
///每个时间点数据 根据 配置 rule 决定数据是否有效，同时判断数据前后间隔是否 在 data_valid_time 配置的时间内，如果超出时间，则不算入有效时间内
///统计有效点占据时间 后 将该条数据 存入关系库（table_name 所配置内容），存入名称为 table_key 所配置内容
```

### 2.拉油

```json
{
	// 结果关系库表名  	
	"table_name":"t_daily_run_status",	
	//执行任务读取的文件，csv文件 	
	"task_file":"运行状态.csv",			
	//统计区间说明 
	//["day",4] : 每日区间 （统计数据时间范围是 {执行时间向前的第一个4点 ，执行时间向前的第二个 4 点 }）配置方式 "interval_time":["day",4]
 	"interval_time":["day",14]
}
```

**数据文件说明**

|表头|​`da_unit`|​`tag`|​`table_key`|​`interval_time`|​`data_valid_time`|​`calc`|
| ------| ----------| --------| ---------| -------------------| -----------------| ---------------------------------|
|表头|采集单元|采集点|入库key|数据获取区间（s）|数据有效时间(s)|产量计算公式，value替代实际产量|
|示例|​`Z01SAGD_1`|​`TIT3102`|​`TEST_KEY`|​`3600`|​`300`|​`{value} * 100 * 0.172`|

**算法说明**

```json
/// 根据 任务配置 说明中的 interval_time 参数 计算数据起止时间
/// 查询 da_unit 以及 tag 参数 对应的采集点起止时间内interval_time 间隔时间 数据，数据有效范围为 data_valid_time 配置时间
/// 计算前后俩个数据差值
/// 获取差值为正值的区间平均值
/// 产量 = 平均值 * ( 区间数量（86400/interval_time 取整）  - 数据差值 ≈ 0 的区间数 )
/// 产量 带入calc 配置计算公式计算最终 大罐产量 （产量 替换公式中的{value} 内容）
```

### 4. 实时数据写入

```json
{
	//需要下发的点数据
	"task_file": "注水模板.csv",				
	 //实时库接口，只改ip
	"url": "http://127.0.0.1:8127/datimsien/mult_control_dev", 
	//目标实时库的节点名称（在实时库的节点管理中查看）
	"node_name":"tim_monitor@127.0.0.1",  
	//目标实时库的ip	
	"ip":"127.0.0.1",						 
	//目标实时库trpc端口，可在实时库sys.config中查看 trpc_server_enable 必须为true采有效 trpc_server_port就是使用的端口
	"port":5372,	
	//是否开启日志统计，开启会导致运行变慢，磁盘空间占用变大，须手动清理日志文件					
	"enable_log":true,
	//token ，只能使用configtazh 的token ，所以必须保证目标服务器有 configtazh的 用户，如果密码没变，可以不配置这项
	"Authorization":"Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJ1c2VyX25hbWUiOls5OSwxMTEsMTEwLDEwMiwxMDUsMTAzLDExNiw5NywxMjIsMTA0XX0.rmC9hAtDRlfqKTAdQEOUWQebMt7aUMA90Cm2L8dDCYQ"
```
